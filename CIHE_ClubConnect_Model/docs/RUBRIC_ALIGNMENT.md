# Rubric Alignment

## 1. Functional Completeness & Business Requirements
- Authentication and two roles
- Two complete CRUD entities: Events and Announcements
- Search, category filtering and pagination
- Client/server validation
- Error/empty-state handling
- Auditability

## 2. System Architecture & Database Design
- Client: semantic HTML/CSS/JS
- Application: PHP modules and shared functions
- Data: MySQL via PDO
- Normalised tables with foreign keys and indexes
- Clear separation into config/includes/modules/assets

## 3. Front-End Quality, UX & Accessibility
- Responsive grid layouts and mobile navigation
- Semantic landmarks and navigation
- Labels for form controls
- Keyboard-visible native controls and skip link
- Consistent feedback, empty states and design system

## 4. Security & Data Handling
- Password hashing
- PDO prepared statements
- Server-side RBAC
- CSRF tokens
- Output escaping
- Server-side validation
- POST-only destructive actions
- Session ID regeneration

## 5. Intelligent / AI-Assisted Feature & Responsible Use
- Integrated Smart Help page
- Local keyword/rule matching
- Useful predefined guidance
- Safe fallback
- User remains in control
- No external AI service
- Limitations clearly disclosed

## 6. Testing, QA & Documentation
- 18-case positive/negative test plan
- README with setup instructions
- AI feature documentation
- This rubric mapping
- Real screenshots/logs must be captured after executing tests

## 7. Presentation, Individual Contribution & Professional Practice
This cannot be manufactured by the application. Demonstrate:
- meaningful commits and pull requests;
- real contribution evidence;
- coordinated live demonstration;
- each member's technical explanation and Q&A.
